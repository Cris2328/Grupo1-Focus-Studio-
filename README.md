# Grupo1-Focus-Studio-
Proyecto de desarrollo de aplicaciones web para la gestión de servicios de fotografía y video.
# 📸 Focus Studio

## Descripción del proyecto

Focus Studio es una aplicación web orientada a la gestión de servicios profesionales de fotografía. Su propósito es facilitar a los clientes la consulta de paquetes fotográficos, visualización de portafolios, disponibilidad de horarios y reservación de sesiones.

Además, proporciona herramientas administrativas para gestionar usuarios, servicios, categorías, reservaciones y disponibilidad del fotógrafo.

Este proyecto se desarrolla como parte del curso de Desarrollo de Aplicaciones Web y Patrones de la Universidad Fidélitas.

## Objetivo general

Desarrollar una aplicación web funcional para la administración de servicios fotográficos, facilitando la interacción entre clientes, fotógrafos y administradores mediante una plataforma organizada, accesible y eficiente.

## Tecnologías utilizadas

- **Java:** lenguaje de programación principal.
- **Spring Boot:** desarrollo de la aplicación web.
- **Thymeleaf:** generación de vistas dinámicas.
- **Bootstrap:** diseño responsivo de las interfaces.
- **HTML y CSS:** estructura y presentación visual.
- **MySQL:** almacenamiento de información.
- **Hibernate/JPA:** persistencia y gestión de datos.
- **GitHub:** control de versiones y colaboración.

## Funcionalidades del sistema

- Visualización y filtrado del portafolio fotográfico.
- Consulta de servicios y paquetes.
- Consulta de fechas y horarios disponibles.
- Registro y gestión de reservaciones.
- Registro e inicio de sesión de usuarios.
- Administración de cuentas de usuarios.
- Gestión de servicios y categorías.
- Administración de disponibilidad del fotógrafo.
- Consulta de estadísticas y actividad del sistema.
